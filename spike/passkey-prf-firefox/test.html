UP Wallet — prova passkey (PRF) / passkey (PRF) test

Fase 0 dell'estensione UP Wallet. Questa pagina crea una passkey di prova (Windows Hello: impronta, volto o PIN) e controlla se il browser ne ricava un segreto (estensione PRF di WebAuthn) dalla pagina dell'estensione. Non crea wallet né chiavi, non legge i tuoi dati e non manda nulla in rete.

Phase 0 of the UP Wallet extension: it creates a test passkey and checks whether the browser derives a secret from it (WebAuthn PRF) from the extension's own page. No wallet, no key, nothing sent anywhere.
